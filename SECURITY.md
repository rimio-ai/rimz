# Security

## Supported versions

Rimz is pre-1.0. Security fixes target the latest released version and `main`.

## Reporting a vulnerability

Report vulnerabilities privately through GitHub Security Advisories on `github.com/rimio-ai/rimz`, or email `security@rimio.ai` if advisories are unavailable.

Include affected versions, reproduction steps, impact, and any known mitigations. Maintainers acknowledge reports privately before public issue tracking.

The threat model and security boundaries live in [docs/guide/security.md](./docs/guide/security.md).
