# Bundled Agent Logos

This directory vendors one SVG identity mark for each of RimZ's eighteen built-in agent kinds. The marks are trademarks of their respective owners. The lobe-icons MIT notice is reproduced verbatim in [LICENSE](./LICENSE); the official-site assets listed below have separate upstream provenance.

Every SVG has a square view box, a transparent background, no root width or height, and a small margin around the mark. The sidebar sizes and centres each mark by the part that paints, so the margin's size and centring do not change how a mark draws. Monochrome geometry uses `currentColor`; branded colours and gradients are retained. Kimi and Qoder retain their tintable geometry alongside their coloured accents. Shared processing removes root layout styles and normalizes the view box without changing path coordinates.

Two source substitutions avoid ambiguous identities. Lobe-icons' `copilot-color.svg` is explicitly [Microsoft Copilot](https://github.com/lobehub/lobe-icons/blob/master/src/Copilot/index.mdx), so GitHub Copilot uses GitHub's own symbol instead. Lobe-icons' `hermesagent.svg` is a portrait that could not be corroborated on Nous Research's current homepage or repository; Hermes therefore uses the homepage's wing, rather than claiming the portrait belongs to a different product.

Amp retains the requested lobe-icons chevrons. Lobe-icons [identifies that mark with ampcode.com](https://github.com/lobehub/lobe-icons/blob/master/src/Amp/index.mdx), but the current Amp homepage and favicon use a wordmark rather than these chevrons. This visual mismatch remains flagged rather than treating a name match as visual verification.

Antigravity retains one mask and eleven SVG blur filters. Codex and Muse use ordinary `userSpaceOnUse` linear gradients; OMP and MiniMax use ordinary bounding-box linear gradients. All references are internal. There are no images, text elements, fonts, scripts, stylesheets, or external references. XML, square geometry, and transparent margins were checked with librsvg at 256 pixels, with light/dark previews at 16 and 96 pixels; resvg itself was unavailable.
