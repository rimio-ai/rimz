Save a Markdown note that outlives this session in the home-wide note store and return its path: a later session or another agent, in any room or checkout, reads it by that path, so cite the returned path word for word wherever you point at the note. RimZ stamps its header with who wrote it and where. `kind` names what the note is: `handoff`, `molt`, `debug`, `reflection`, or one word of your own. Give the body inline, or a `file` you already have (a report, a subagent's output, a log) and from then on cite the note's path in place of the file's. `fence` wraps text that is not Markdown (a log, command output) in one code block. A `meta` key is a fact to find the note by later (`{"pr": "482"}`), which a `notes_list` filter names.
