Each `filter` term must match, and a term names a header field or a `meta` key by its own name: `kind=handoff`, `author=otter`, `pr=482`, `age<2d`. A term is `<field><op><value>[,<value>...]`: under `=` any value matches and under `!=` none may; `age` and `written` also take `>`, `>=`, `<`, and `<=`. Fields: `kind`, `title` (words, any case), `author` (an agent name, `@` optional), `written` (RFC 3339), `age` (`30s`, `5m`, `1h`, `2d`), `project`, `worktree`, `profile`, `team`, `role`, `model`, `channel`, `loop-task`, `loop-fire`, `workflow-run`. `*` matches any present value and `none` a missing one; quote a value that holds spaces or commas. The filter `help` prints every field and operator. More than 20 matches: narrow the filter.
