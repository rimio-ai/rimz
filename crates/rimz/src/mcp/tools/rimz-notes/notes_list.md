Search every note in the RimZ home, whatever room or checkout wrote it, and list the newest matches oldest first, so the newest is the last row (20 unless `limit` says otherwise). Every `filter` term must match. A term is `<field><op><value>[,<value>...]`: under `=` any value matches and under `!=` none may; `age` and `written` also take `>`, `>=`, `<`, and `<=`. Fields: `kind`, `title` (words, any case), `author` (an agent name, `@` optional), `written` (RFC 3339), `age` (`30s`, `5m`, `1h`, `2d`), `project`, `worktree`, `profile`, `team`, `role`, `model`, `channel`, `loop-task`, `loop-fire`, `workflow-run`; any other field is a `meta` key, matched as written. `*` matches any present value and `none` a missing one; quote a value that holds spaces or commas. Examples: `kind=handoff`, `author=otter`, `age<2d`, `pr=482`. The filter `help` prints every field and operator.
