When the user asks, report or change one of your own settings for this session; no configuration changes. Give no `setting` to report each setting and where its value comes from. `keep-warm` (`2h`) keeps the prompt cache warm for up to that long of rest after each turn. `idle-compact` (`120k`) compacts at rest, before the cache expires, once context reaches that size. `smart-compact` (`70%`, or a token count such as `200k`) wraps up and compacts at that share of the window. Each also takes `off`, and `reset` drops the override, back to the configured value. The override holds through the session's restarts and resumes; a molt or fork starts without it.
