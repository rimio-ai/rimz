End one thing you started, or one an agent you started started: a subagent or an agent with its own subagents, every seat of a team (its checkout and board stay), a shell, a watch, a schedule, or a workflow run. Stopping a schedule removes its booking and backlog while letting already-started runs finish, listed under `still_running` (a fire that has not yet published a record is not named). Cancelling a workflow run is the user's call: stop one only when the user asks; runs it started go on, listed under `still_running`. A team's id names its lane, so stop a team soon after `tasks` lists it: a later team in the same lane answers to the same id. A thing already ended returns `status: "ended"` as a value. Anything another agent started, or a provider-native background task or subagent id, is refused (end provider-native ones with your provider's own tool).
