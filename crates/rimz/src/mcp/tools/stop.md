End one thing you started, or one an agent you started started, by its `id` as `tasks` or a start answered it: a subagent or an agent with its own subagents, every seat of a team (its checkout and board stay), a wait, a schedule, or a workflow run. Stopping a schedule removes its booking and backlog and lets every run it already started finish; the answer lists each by id under `still_running`, empty when none runs, though a fire whose process has published no record yet is not named. Cancelling a workflow run is the user's call: stop one only when the user asks; the runs it started go on, listed under `still_running`. A team's id names its lane, so stop a team soon after `tasks` lists it: a later team in the same lane answers to the same id. A thing that ended before the call answers `status: "ended"` as a value, so a loop over `tasks` never races what finishes first. A thing another agent started is refused. An id of another shape, such as one your provider gave its own background task or native subagent, is refused: end that with your provider's own tool.
