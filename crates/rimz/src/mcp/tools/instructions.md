A tool acts as this agent, in its room, unless its description says otherwise. A tool with an output schema answers a JSON object of that shape, as structured content and as its text; a tool without one answers text. A call that cannot do its job returns an error result whose text is a JSON object with `error` and, when the fix is known, `hint`. Arguments that do not fit a tool's schema return one whose `error` starts `invalid arguments:`, and nothing runs.
