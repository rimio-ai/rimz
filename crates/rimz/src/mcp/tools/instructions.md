Each tool but `guide` runs one `rimz` command as this agent, in its room, and returns that command's output: its stdout, then a `stderr:` line and its stderr when it wrote any. A command that exits nonzero returns an error result whose last line is `exit code N`. Arguments that do not fit a tool's schema return `invalid arguments: ...`, and nothing runs. `guide` is answered by the server itself, with the text of the guide it names.
